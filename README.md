### 💡 What I care about

- **Accessibility isn't optional** — skip links, visible focus states, reduced-motion support, layouts tested down to 320px.

- **Honest data** — when a guide says "verified", there's a source link behind it.
- **Boring reliability** — graceful errors, throttling, ownership-scoped queries, no secrets in code.
